[#confirmation]
= Input: Confirmation

The `confirmation` type argument is a special argument type, which simply disables the "Start" button until a checkbox is ticked. This can be useful if you have an action with no other arguments, but you want to prevent accidental button-clicks starting the action.

Confirmation arguments are usually left unnamed, so nothing is substituted into the command. If you do give the argument a `name`, the only allowed values are `0` (unchecked) and `1` (checked), so confirmation is safe to use with `shell:` actions.

[NOTE]
====
The checkbox guards against accidental clicks in the web UI; it is not an access control. An unnamed confirmation is not checked by the API, so calling xref:api/method_StartAction.adoc[StartAction] (or a custom web UI, or a script) starts the action without it. A named confirmation must be sent by API callers, but both `0` and `1` are accepted. To limit who can start an action, use xref:security/acl.adoc[access control lists].
====

[source,yaml]
----
actions:
  - title: Delete old backups
    icon: ashtonished
    shell: rm -rf /opt/oldBackups/
    arguments:
      - type: confirmation
        title: Are you sure?!
----
